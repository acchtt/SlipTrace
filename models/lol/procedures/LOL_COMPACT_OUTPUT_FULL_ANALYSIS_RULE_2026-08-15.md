# LoL Compact Output / Full Analysis Rule — 2026-08-15

**Status:** Mandatory execution procedure addendum
**Applies to:** LoL v0.3.59 live shadow audit and all chats that load its execution procedures
**Model impact:** None. This is an execution rule only and does not create a new model version.

## Core rule

**Response brevity is an output constraint only. It must never reduce, skip, merge, abbreviate, or replace the analytical procedure.**

For every draft classification and every live screenshot, complete the full applicable model/rules/procedure stack before issuing the verdict, even when the visible reply is only a few lines.

## Mandatory execution

Before the visible verdict, internally complete every applicable retained gate for all relevant market families. Preserve draft primacy, draft-locked classifications and vetoes, synchronized-snapshot requirements, exact signed-margin arithmetic, market-specific qualification rules, executable/stale-line checks, minimum odds, correlation controls, and genuine position-blind reassessment where allowed.

A compact reply must never be produced by checking only the most visually obvious feature of the state or by stopping after the first plausible reason.

For any underdog +kills evaluation, the full v0.3.57 fail-closed certification remains mandatory and draft-locked. Brevity is never permission to omit FER, PDC, PST, ARI, False-Stable Guard, FF, or the hard Draft-Collapse Veto.

## Visible named-gate audit

The first visible line remains the required compact `TAKE / PASS / HOLD — market @ odds — stake` verdict.

After that first line, give a concise named-gate audit:

- `PASS` or `HOLD` after live eligibility must identify the specific failing named gate or veto.
- `TAKE` must identify the decisive passed gate(s) and required arithmetic/pricing basis.
- The wording may be brief; the underlying evaluation may not be partial.

## Prohibited compression failures

The following are execution errors:

- skipping a required rule because the user requested a brief reply;
- declaring a draft classification without completing its mandatory certification tests;
- replacing a required framework with a generic impression such as “looks safe,” “good range,” “fast game,” or “needs more confidence”;
- omitting a hard veto or draft lock because live evidence looks attractive;
- failing to scan all four market families on a materially new synchronized live state;
- allowing a chat switch, handoff compression, or response-length preference to reduce the number of gates checked.

If visible brevity conflicts with procedural completeness, **procedural completeness always wins internally; only the wording is compressed.**
