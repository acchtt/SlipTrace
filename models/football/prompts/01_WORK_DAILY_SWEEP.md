# 01 — Work: Football C Integrated Board

Read upstream `models/football/CURRENT_MODEL.md` first, then load `models/football/production/FOOTBALL_C.md`.

Football C is the active official model.

Use the attached `AISCORE_FIXTURES_*.zip` produced by Step 0. Validate the ZIP and canonical root-level `AISCORE_FIXTURES_*.txt` handoff before research. Do not rebuild the raw fixture universe.

If the package is invalid or the actionable handoff is incomplete, stop rather than researching a partial slate.

## Task

Run **one integrated Football C screen/research/rank pass** over the common eligible senior fixture universe.

Do not invoke:
- `FOOTBALL_PRE_DECISION_SPEC.md`;
- Football A grades/patches;
- HMA;
- carrier-market decomposition;
- priority inversion;
- market-alignment gates;
- Football A Step-2 logic.

For each eligible fixture:

1. verify identity/time/status from the handoff;
2. research current football evidence;
3. classify both scoring routes as STRONG / USABLE / WEAK;
4. classify carrier as STRONG / USABLE / NONE;
5. assess current chance quality;
6. run the required relevant H2H/matchup check, prioritizing recent same-venue transferable evidence;
7. state the dominant failure mode;
8. choose Football C supported burden before price;
9. rank survivors directly against the rest of the slate;
10. assign C-FOCUS / C-WATCH / C-PASS.

No fixed board-size cap. Quality first.

## Market boundary

Step 1 is structural and does not require the user's current executable odds.

Do not rank by price and do not manufacture market information.

## Persistence

Persist the frozen Football C board to Daily Coverage Ledger where practical:
- model identity in notes/summary = Football C;
- ordinal C rank;
- Board Tier mapped from C-FOCUS/C-WATCH/C-PASS;
- Frozen PRE Summary containing routes, carrier, supported line, failure mode, H2H state and evidence confidence.

Do not overwrite historical Football A frozen rows.

## Output

Return:

`FOOTBALL C BOARD <window>`

| Rank | Match | C state | Routes | Carrier | Supported line | Main failure | Initial action |
|---|---|---|---|---|---|---|---|

Initial action at board time is normally `REVIEW AT XI` or `PASS`; Football C does not invent executable prices before the user supplies them.

Then give a short follow-up schedule for C-FOCUS/C-WATCH matches based on kickoff time.

Keep the report compact. The purpose is to identify the best football opportunities, not create a large bureaucracy of intermediate labels.
