# Football audit hindsight integrity

Audit frozen prospective evidence without allowing the result to rewrite what
the model knew before kickoff.

## Active model

Football C is the only active model.

For current/prospective rows audit:

- Step-0 admission/screening;
- C rank/board/lane;
- C certified burden and certificates;
- /xi C football state and action when executed;
- WAIT reachability;
- official C model exposure;
- user physical exposure only from Actual Bets — Current.

## Retired historical models

C2/C3/C4 may be shown only when their decisions genuinely existed
prospectively. Never backfill or reconstruct a missing retired-model judgment
after the result. They have zero current production authority.

## Hindsight rules

Do not:

- change a frozen prematch grade because the final score was high/low;
- infer a missing quote;
- turn an incomplete assessment into PASS;
- create WAIT_ASSUMED / WATCH_ASSUMED exposure;
- count a Website Pick or model action as a physical user bet.

Use final outcomes to diagnose classes such as screening miss, ranking
inversion, certificate false positive/negative, availability asymmetry,
unreachable WAIT and process/execution miss.

Any model change must be justified by facts available prospectively and tested
against positive and negative controls.

Unresolved WAIT creates no model exposure and no model P/L. WATCH is
classification only. Actual Bets — Current is the sole physical P/L authority.
