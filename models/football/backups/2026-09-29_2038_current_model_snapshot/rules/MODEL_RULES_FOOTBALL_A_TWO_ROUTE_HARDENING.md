# Football A — Two-Route Hardening Patch

**Status:** ACTIVE — prospective only  
**Effective:** 2026-09-23 10:27 ICT  
**Scope:** Football A structural classification, ranking, supported burden, and exposure eligibility  
**Historical protection:** Do not retroactively reclassify frozen historical decisions or P/L.

## 1. Purpose

Recent audit evidence shows that Football A has been over-crediting nominal route symmetry in A2, especially when the weaker route is only SUPPORTED by score/form proxy, opponent leakage, BTTS frequency, H2H, or game-state assumptions.

The model must distinguish a genuinely independent second scoring route from a merely plausible/conditional one.

Core invariant:

`TWO-SIDED != AUTOMATICALLY SAFER`

and:

`A2 ROUTE SYMMETRY WITHOUT INDEPENDENT SECOND-ROUTE PROOF DOES NOT EARN FOCUS PRIVILEGE`

## 2. New route-quality label

For every A2 TWO-SIDED candidate, classify the weaker route as one of:

- `INDEPENDENT SECOND ROUTE`
- `CONDITIONAL SECOND ROUTE`

### INDEPENDENT SECOND ROUTE

The weaker route is independent only when current evidence shows it can create/convert scoring against comparable resistance without relying mainly on opponent collapse.

At least one hard proof must be present:

- strong current chance quality / shot-quality creation;
- repeatable current scoring against comparable or stronger opponents;
- confirmed-XI attacking construction preserving the route;
- verified tactical/game-state mechanism that creates chances regardless of the opponent gifting territory.

Recent scoreline frequency alone is insufficient.

### CONDITIONAL SECOND ROUTE

Label the weaker route conditional when it depends materially on one or more of:

- opponent leakage/concession profile;
- BTTS or Over frequency without underlying creation proof;
- H2H scorelines;
- isolated recent high scores;
- score/form proxy;
- away/venue-sensitive contribution;
- "must chase" or similar game-state assumption without independent creation proof;
- opponent mistakes / red-card style failure branches;
- confirmed XI that preserves names but not demonstrated chance creation.

## 3. A2 tier consequences

### PROVEN + SUPPORTED

- If the SUPPORTED route is `INDEPENDENT SECOND ROUTE`, normal A2 FOCUS remains possible subject to existing chance-quality, failure-resistance, burden and XI gates.
- If the SUPPORTED route is `CONDITIONAL SECOND ROUTE`, cap at `A2 WATCHLIST`.
- The cap may be cleared only by:
  - `TRUE CC+` / `PRACTICAL CARRIER CEILING — VERIFIED` on the stronger side that independently supports the required total; or
  - direct strong chance-quality evidence upgrading the weaker route to `INDEPENDENT SECOND ROUTE`.

### SUPPORTED + SUPPORTED

- Default maximum is `A2 WATCHLIST`.
- `A2 FOCUS` is allowed only when **both** routes independently clear strong current chance-quality / creation proof and confirmed XI preserves both mechanisms.
- Generic two-sidedness, recent BTTS, recent Over rate, and mutual defensive leakage do not clear FOCUS.

## 4. Ranking consequence

Route symmetry is a late tie-breaker only.

For A2 TWO-SIDED ranking, use:

`VERIFIED SELF-FUNDED 3+ PATH > INDEPENDENT SECOND ROUTE > CHANCE QUALITY / URGENCY > FAILURE-MODE RESISTANCE > CONDITIONAL SECOND ROUTE > ROUTE SYMMETRY`

A verified carrier-led B+ or A2 may rank above a generic A2 TWO-SIDED fixture when its 3+ mechanism is more failure-resistant.

## 5. Supported-burden consequence

Supported burden must come from the reliable 3+ mechanism, not from adding two weak one-goal routes together.

- A conditional second route cannot by itself raise burden.
- If the primary route supports only a 2-goal carrier state and the second route is conditional, cap the total accordingly.
- For a generic A2 TWO-SIDED with one conditional route, prefer the lower protected burden and do not use route symmetry as justification for O2.75/O3.0.
- O3.0+ still requires the existing upper-tail proof.

## 6. XI stage

Confirmed XI does not automatically validate a second route merely because expected attackers start.

At XI review ask:

1. Is the weaker route's actual creation mechanism present?
2. Is there current comparable-opponent evidence that it can generate enough chances?
3. Is the route independent of opponent collapse?

If not, persist:

`CONDITIONAL SECOND ROUTE — XI NAMES PRESERVED, MECHANISM NOT HARDENED`

and keep the A2 WATCHLIST cap.

## 7. Exposure consequence

An A2 TWO-SIDED fixture capped by this patch may still execute at an exact supported protected line if all normal Football A execution rules allow it.

This patch does **not** create a blanket no-bet rule. It changes structural confidence, rank, supported burden, and FOCUS privilege.

Decay-first remains final authority over above-burden execution.

## 8. Persistence

For every new A2 TWO-SIDED assessment persist:

- weaker-route label: `INDEPENDENT SECOND ROUTE` or `CONDITIONAL SECOND ROUTE`;
- proof used;
- whether FOCUS cap applies;
- primary 3+ mechanism;
- whether burden relies on route addition;
- revised supported burden/ceiling if affected.

## 9. Audit

Track prospectively:

- independent-route A2 FOCUS;
- conditional-route A2 WATCHLIST;
- SUPPORTED+SUPPORTED cases denied FOCUS;
- verified-carrier overrides;
- 3+ hit rate and official P/L for each group.

This patch is prospective and does not rewrite prior frozen grades, picks, or results.
