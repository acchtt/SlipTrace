## Production workflow

1. `prompts/00_NORMAL_CHAT_AISCORE_FETCH.md` — AiScore fixture discovery/time/scope handoff.
2. `prompts/01_WORK_DAILY_SWEEP.md` — one integrated C screen/research/rank pass.
3. `prompts/02_NORMAL_CHAT_XI_ODDS.md` — one integrated XI + fresh web research + H2H + price decision.
4. `prompts/03_NORMAL_CHAT_LIVE.md` — predeclared WAIT resolution with thesis-health check.
5. `prompts/04_WORK_POST_SLATE_AUDIT.md` — version-faithful settlement and process audit.

Football C emits only:
- C-BET
- C-WAIT
- C-PASS
